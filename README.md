# Vekselstrøm og RC-kretser

Pugge-side for FEM1134 Elektriske kretser / Kretsteknikk ved UiA, laget ut fra Øving 5.

## Innhold

1. **Sinusspenning**: toppverdi, vinkelfrekvens, frekvens, periodetid og effektivverdi. Med et interaktivt oscilloskop.
2. **Motstand på vekselspenning**: strøm, middeleffekt og energi i kWh.
3. **Spole og kondensator**: reaktans og faseforskyvning, med oscilloskop for R, L og C.
4. **RC-krets og sprang**: opp- og utladning, tidskonstanten τ = RC og strømmen gjennom R.
5. **Trening**: oppgaver med nye tall hver runde, svarsjekk og løsning steg for steg.

Alle deloppgavene i øving 5 er løst steg for steg på siden.

## Bruk

Åpne `index.html` i nettleseren. Hele siden ligger i én fil. Matematikken vises med MathJax, som lastes fra jsDelivr, så du trenger internett.

## Publisere med GitHub Pages

Gå til **Settings → Pages** i repoet. Under *Branch* velger du `main` og `/ (root)`, og trykker **Save**. Etter et minutt eller to ligger siden på `https://<brukernavn>.github.io/<repo-navn>/`.
